# DS483 Project - SMS Spam Detection

Our project for the NLP course (DS483).
We try different models to find if an SMS message is ham (normal) or spam.

## Files

- DS483_SMS_Spam.ipynb - our notebook
- report_draft.md - our report
- data/SMSSpamCollection - the data

## Plan

- Week 1: text preprocessing
- Week 2: TF-IDF and cosine similarity
- Week 3: Naive Bayes and Logistic Regression
- Week 4: LSTM
- Week 5: BERT

## How to run

Open the notebook in Google Colab and click Runtime -> Run all

## Data

SMS Spam Collection from UCI
https://archive.ics.uci.edu/dataset/228/sms+spam+collection
